## 📄 Pages
| File | Description |
|------|-------------|
| `index.html` | Homepage — hero banner, featured products, accessories banner |
| `shop.html` | Products page — filterable grid (All / Clothing / Accessories / Shoes) |
| `product.html` | Product detail — size selector, add to cart, reviews |
| `cart.html` | Cart — items, order summary, explore more |

## ✨ Features
- 🛒 **Working Cart** — add/remove items, persists via localStorage
- 🔍 **Category Filters** — All, Clothing, Accessories, Shoes
- 📦 **24 Products** — with real Unsplash photography
- 📱 **Responsive** — works on mobile and desktop
- 💛 **Luxury Design** — gold + black palette, Cormorant Garamond serif

## 🗂️ File Structure

## 🚀 How to Run Locally
Just open `index.html` in your browser — no server needed!

## 🌐 Deploy to GitHub Pages
1. Push all files to your GitHub repo
2. Go to **Settings → Pages**
3. Source: **Deploy from a branch** → `main` → `/ (root)`
4. Save — your site is live in ~1 minute!
